The Jakarta Concurrency 3.1 feature (`concurrent-3.1`) provides the implementation of the Jakarta Concurrency 3.1 specification for Jakarta EE 11. This version introduces deeper integration with CDI, support for Java 21 virtual threads, and the ability to schedule asynchronous methods without requiring EJB.

If you are updating your application from using the `concurrent-3.0` feature to using the `concurrent-3.1` feature, changes in API behavior might require you to update your application code. For more information, see xref:diff/jakarta-ee11-diff.adoc#concur[Differences between Jakarta Concurrency 3.1 and 3.0].
