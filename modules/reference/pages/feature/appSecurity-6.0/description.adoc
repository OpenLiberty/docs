This feature enables support for securing the server runtime environment and applications using Jakarta Security 4.0.

If you are updating your application from using the `appSecurity-5.0` feature to using the `appSecurity-6.0` feature, the removal of a single, previously deprecated Jakarta class might require you to update your application code. For more information, see xref:diff/jakarta-ee11-diff.adoc#security[Differences between Jakarta Security 4.0 and 3.0].
