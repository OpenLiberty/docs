WebSphere Liberty allows you to configure a reader role and an administrator role.

Administrator role:: Has all privileges in the Liberty server, including the ability to perform POST, PUT, DELETE, and GET operations. Grants users read and write access to administrative REST APIs, including the ability to modify their configuration or settings.

Reader role:: Also known as the reader-role. It is a built-in management and authorization role used primarily to grant secure, read-only access to server operations, JMX metrics, and the Admin Center. Grants users the same permissions to monitor the server as in the administrator role, but without the ability to modify any configuration or settings. The reader role provides access to REST APIs that are considered read-only. Users in this role can monitor the server, but cannot modify it in any way. The reader role also provides administrative access to JMX methods and MBeans that are considered read-only.
+
The expectations for the reader role include:
+
* *Server Monitoring:* Ability to view server status, CPU/heap utilization, and OSGi bundle status.
* *Read-only JMX Access:* Safe access to read-only JMX MBeans and performance metrics through the REST Connector.
* *Admin Center Access:* Ability to navigate the Admin Center Toolbox to check running/stopped applications and view log files safely without modifying server configurations.
+
Limitations for the reader role:
+
* *No Modifying Configurations:* Readers cannot alter `server.xml` or other configuration files.
* *No Lifecycle Control:* Readers cannot start, stop, deploy, or update applications.
